# Claude Code Workflow

Before significant work, inspect the relevant implementation and the linked documentation in `docs/`. Plan the smallest cohesive change before editing.

After meaningful changes, use an independent read-only review when practical. Verify reviewer findings before fixing them; do not assume a reported issue is correct.

Run the relevant checks from [Testing](docs/TESTING.md) before declaring work complete. Report checks that could not be run and why.
